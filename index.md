# Alexaa Devi YouTube Automation

**Alexaa Devi YouTube Automation** is a private automation tool used by its owner to upload and manage video content on their own YouTube channel.

## What this application does

The application uses Google's YouTube Data API to:

- Upload videos and YouTube Shorts to the owner's YouTube channel.
- Set video titles, descriptions, tags, and visibility settings.
- Automate publishing through a server-side workflow.

The application is not a public social network or a service for managing other people's YouTube channels.

## Google / YouTube access

When the owner connects a YouTube account, the application uses Google OAuth 2.0 to obtain permission to upload videos on that account's behalf.

The application requests only the permissions needed for its intended YouTube functionality.
